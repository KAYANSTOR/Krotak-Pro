# المرحلة 62 — عملة ملف العميل دون خلط الدفتر

**التاريخ:** 2026-10-02  
**الفرع:** `development/full-completion`  
**الأصل:** خارج نطاق المرحلة 61: «تغيير عملة ملف العميل أو الدفتر نفسه».

## التنفيذ

- ملف العميل يعرض الرصيد والملخص وسجل العمليات بعملة واحدة مختارة.
- العملات المتاحة تُستخرج من حركات الحساب، والريال اليمني يبقى الافتراضي.
- تصدير PDF ومشاركة الكشف وتعديل الرصيد يستخدمون عملة العرض، فتُسجَّل الحركة الجديدة بعملتها دون تحويل القديم.
- الحركات بعملة أخرى تبقى في الدفتر ولا تُجمع مع رقم العرض.

## خارج النطاق

- عملة أساسية دائمة للحساب تُحوّل كل الحركات التاريخية.
- تحقق جهاز حقيقي وأي عمل ترخيص.
