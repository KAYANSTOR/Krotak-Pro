## ج) المرحلة 7 الموسّعة — الكروت والمخزون والاستيراد (تفصيل كامل)

**الهدف:** مطابقة 100% بصرية + عملية + Domain مع فيديو Z Net وتبويب «الكروت» في التطبيق.

**الملفات الحالية:**
- `lib/ui/screens/inventory_screen.dart`
- `lib/ui/screens/inventory_widgets.dart` (part)
- `lib/ui/screens/inventory_sheets.dart` (part)
- Domain: `CardCatalogService` / `CardImportParser` / `Card` / `CardCategory` / `reserved_card_ops`

### 7.0 — منطق العمل الحقيقي (كما يجب أن يعمل — مطابق للفيديو)

```
فئات الكروت (CardCategory)
  └─ اسم + قيمة اسمية (faceValue) + isActive
  └─ تُنشأ من شاشة الكروت → «الفئات» → فئة جديدة
  └─ تظهر فوراً كشرائح فلترة: «كرت 100»، «كرت 200»…

كروت المخزون (Card)
  └─ serialNumber + secretCode + categoryId + status
  └─ الحالات: available | reserved | sold | disabled | expired
  └─ الاستيراد: فردي أو دفعة (TXT/CSV) عبر CardImportParser
  └─ لا يُسمح بتكرار السريال

البيع / الصرف
  └─ available → reserved (حجز) → sold (بعد التسليم)
  └─ الكروت المحجوزة: عمليات من showReservedCardOps
  └─ انخفاض المخزون: بانر في اللوحة عند عبور عتبة SettingKeys.lowStockThreshold

الاستيراد
  └─ TXT/CSV مدعوم
  └─ Excel جزئي
  └─ شاشة «إدارة ملفات الاستيراد» تظهر الملفات بعد الاستيراد (إن وُجدت في الفيديو)
```

### 7.1 — الهيكل البصري المطلوب (من الفيديو + الكود الحالي)

| عنصر UI | المطلوب |
|---------|---------|
| **الهيدر** | عنوان يمين (RTL) + أيقونات يسار (قائمة / إضافة / حذف أو ما يظهر في الإطار) |
| **أزرار علوية** | «الفئات» + «إضافة الكروت» — زرّان متساويان |
| **بحث** | حقل «البحث برقم الكرت...» |
| **شرائح الفئات** | الكل + كرت {قيمة} لكل فئة نشطة (ألوان مميزة) |
| **فلاتر الحالة** | الكل · كروت متوفرة · كروت مستخدمة |
| **بطاقة التذكرة** | سريال · السر · الحالة · القيمة الاسمية · شكل تذكرة |
| **الكروت المحجوزة** | الضغط يفتح عمليات (إرسال / إلغاء حجز / تأكيد صرف) |
| **إنشاء فئة** | Bottom sheet: اسم + قيمة بالريال + تحقق عربي + إبقاء الورقة مفتوحة عند خطأ |
| **إضافة كروت** | اختيار فئة + فردي أو لصق/ملف دفعة |

### 7.2 — خطوات الإغلاق (معيار كل خطوة)

| خطوة | العمل | معيار الإغلاق |
|------|--------|----------------|
| 7.1 | مطابقة الهيدر والأزرار العلوية مع الإطار | لقطة جهاز تطابق |
| 7.2 | شرائح الفئات + فلاتر الحالة تعمل على بيانات Drift | فلترة فورية صحيحة |
| 7.3 | بطاقة تذكرة: سريال/سر/حالة/قيمة | لا أسرار ناقصة؛ نسخ اختياري إن في الفيديو |
| 7.4 | إنشاء فئة: اسم + قيمة + رسائل عربية + Domain `saveCategory` | فئة تظهر فوراً في الشرائح |
| 7.5 | استيراد فردي + دفعة TXT/CSV عبر `CardImportParser` + `importCards` | لا تكرار سريال؛ عداد مستورد |
| 7.6 | عمليات الكرت المحجوز (`showReservedCardOps`) | إرسال/إلغاء/تأكيد يغيّر الحالة فعلياً |
| 7.7 | ربط بانر انخفاض المخزون في اللوحة بـ `lowStockThreshold` | يظهر عند عبور العتبة فقط |
| 7.8 | شاشة/قسم ملفات الاستيراد إن ظهر في الفيديو | قائمة ملفات أو empty state واضح |
| 7.9 | تحسين Excel إن بقي جزئياً | استيراد صفوف صحيحة أو رسالة خطأ واضحة |

### 7.3 — مصادر البيانات (إلزامي — لا Mock)

| عملية | المصدر |
|--------|--------|
| قائمة الفئات | `categories.listAll()` → النشطة فقط في الشرائح |
| قائمة الكروت | `cards.listByStatus` لكل الحالات ثم دمج/فلترة محلياً |
| حفظ فئة | `catalogService.saveCategory` |
| استيراد | `catalogService.importCards` + `CardImportParser` |
| عمليات محجوز | `reserved_card_ops` / خدمات الصرف |

### 7.4 — قواعد صارمة للكروت

1. لا فئة بلا قيمة اسمية موجبة.
2. لا كرت بلا سريال وسر.
3. السريال فريد على مستوى قاعدة البيانات.
4. الحالة تنتقل بمسارات Domain فقط (لا تغيير status من UI مباشرة بلا خدمة).
5. الاستيراد دفعة واحدة ذري قدر الإمكان مع Audit.
