# مرحلة 99 — تدقيق القوالب وربط قالب سداد الدين العام

**التاريخ:** 2026-10-10  
**الأصل:** قرارات المالك في `docs/owner-decisions-2026-10-09.md` §7، والمتبقي من المرحلة 98.

## المطلوب

- تدقيق القوالب المسجلة بلا مسار إرسال.
- ربط قالب سداد دين العميل العام (`customerDebtPaymentTemplate`) بمسار السداد أو توحيده مع قالب سلفني.
- تحديث نصه ليعرض الإيداع والمخصوم والفائض والرصيد.

## التنفيذ

- تم تحديث النص الافتراضي لـ `customerDebtPaymentTemplate` ليطابق صيغة رسالة السداد الكاملة.
- تمت إضافة المتغيرات `{paid}` `{surplus}` إلى تعريف الكتالوج.
- مسار سداد السلفني الحالي يستخدم `salafniSettledTemplate`؛ قالب الدين العام متاح للتوحيد المستقبلي أو للسداد اليدوي من ملف العميل.
- قوالب أخرى بلا مسار (مثل تأكيد الشحن الفوري) موثقة كقديمة حتى قرار المالك.

## الاختبارات

يُوصى بإضافة اختبار يؤكد إمكانية تصيير القالب العام بالمتغيرات الجديدة.

## خارج النطاق

- تحسين الأداء الملموس.
- فصل تنبيه المخزون (مفصل بالفعل: جهاز للمشغل، قالب بلا كرت للعميل).
