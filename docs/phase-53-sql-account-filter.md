# المرحلة 53 — فلتر الدين داخل SQL

**التاريخ:** 2026-10-01
**الفرع:** `development/full-completion`
**الأصل:** خارج نطاق المرحلة 52: فلتر المدين/الدائن/الصفر كان يُطبَّق بعد قراءة الصفحات.

## التنفيذ

- `searchFilteredPage` يحسب الرصيد الموقّع من الحركات المكتملة فقط بعملة الطلب.
- المدين والدائن والصفر والمؤقت وبلا رقم تُصفّى داخل SQL، والحساب المدمج مستبعد.
- شاشة الحسابات تعيد التحميل من هذا الاستعلام عند اختيار فلتر غير «الكل»، بحد 2000 صف.
- تصدير CSV/PDF يقرأ صفحات المطابقين فقط، ثم يبقى حد 5000 صف من المرحلة 52.
- الحركة المعلّقة لا تدخل الرصيد.

## خارج النطاق

- ترتيب الرصيد داخل SQL لكل الصفحات.
- تحقق جهاز حقيقي.
- أي عمل ترخيص.
