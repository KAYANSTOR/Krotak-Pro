# قائمة تحقق الجهاز — المرحلة 8

**الغرض:** إغلاق بوابة §23 على جهاز أندرويد حقيقي.  
**لا تُستبدل باختبارات الوحدة.**

علّم كل بند: نجاح / فشل / لا ينطبق. أي فشل حرج = غير جاهز للنشر التجاري.

## البناء والتوقيع

- [ ] الأسرار الأربعة موجودة في المستودع
- [ ] `workflow_dispatch` على `main` يبني `krotak-pro-release-apk`
- [ ] السجلات لا تطبع كلمة مرور أو محتوى JKS
- [ ] Application ID = `com.kayan.net_app`
- [ ] تثبيت APK يحدّث النسخة الحالية إذا كان المفتاح نفسه
- [ ] الاسم الظاهر: كروتك برو / Krotak Pro
- [ ] الأيقونة والـSplash مطابقان للهوية

## الصلاحيات والنظام

- [ ] طلب صلاحيات SMS عند الحاجة
- [ ] رفض واضح إذا رُفضت الصلاحية
- [ ] Notification Listener يُفتح من الإعدادات بعد تفعيل محفظة إشعار
- [ ] الحالة تعكس الإذن الفعلي
- [ ] بعد إعادة التشغيل: الاستقبال يعمل
- [ ] بعد قتل التطبيق: العامل يسترد الطابور دون تكرار مالي

## الرسائل والمسار التجاري

- [ ] بيع مباشر: أول رقم يُظهر اقتراحات حقيقية
- [ ] POS قالب 1: `10 كروت 100` من رقم نقطة البيع
- [ ] POS قالب 2: `١ كرت 100 7xxxxxxxx` يرسل للعميل ويؤكد للنقطة
- [ ] POS قالب 3: `111` يرد بالرصيد ويحترم الحد اليومي
- [ ] تجاوز سقف الدين: لا حجز ولا إرسال + رفض + تدقيق
- [ ] سلفني من رقم نقطة بيع مرفوض
- [ ] سلفني لعميل مؤهل يعمل
- [ ] زمن الاستلام → بدء الإرسال < 10 ثوانٍ محلياً
- [ ] إعادة معالجة رسالة ناجحة لا تعيد الخصم ولا تعيد إرسال الكرت
