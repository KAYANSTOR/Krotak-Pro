# مرحلة 69 — نافذة أوسع لطابور الفئة والطابور المشترك

**التاريخ:** 2026-10-04  
**الأصل:** مرحلة 68 توسّع طابور العميل عبر الفئات إلى 32 كرتاً و7 أيام، وتترك طابور الفئة والطابور المشترك عند 8 كروت و24 ساعة.

## القرار

طابور الفئة بلا عميل، والطابور المشترك عبر الفئات بلا عميل، يقبلان حتى 32 كرتاً ويبقيان صالحين 7 أيام. إضافة كرت جديد تمدّد انتهاء الطابور إلى الموعد الأبعد. حجز الكرت في المخزون يستخدم المدة نفسها حتى لا يُحرَّر قبل انتهاء الطابور.

طابور العميل داخل الفئة الواحدة يبقى عند 8 كروت و24 ساعة، ولا يختلط بالطابور العريض. طابور العميل عبر الفئات يبقى كما في مرحلة 68.

لا قيد دفتر ولا بيع عند الحجز. خصم المخزون يبقى عند الصرف الفعلي فقط.

## خارج النطاق

- ضمان وصول الرسالة على جهاز حقيقي يبقى عند المالك وتقرير الناقل.
- لا إلغاء سقف الطابور بالكامل، حتى لا يتضخّم JSON الإعدادات.
- لا تمديد لطابور العميل داخل الفئة الواحدة.
