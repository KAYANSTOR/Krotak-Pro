# إصلاحات واجهة — إشعارات / استيراد / قوالب

**التاريخ:** 2026-09-21  
**التطبيق على:** بعد دفع `krotak-full-completion-1-to-pdf-complete`

## المرحلة A — إشعارات المحافظ
- شاشة فرعية كاملة تعمل: حالة الإذن، قائمة المصادر، تفعيل/إيقاف، حذف، إضافة، مزامنة من المحافظ.
- حالة فارغة واضحة بدل هيكل تحميل صامت.

## المرحلة B — استيراد من ملف
- زر «استيراد من ملف» يفتح مسار ملف فقط (PDF/XLSX/CSV) وليس ورقة الإضافة اليدوية.
- زر `+` يبقى للإضافة اليدوية (مفرد / مجموعة).

## المرحلة C — أزرار متغيرات القوالب بالعربية
- شرائح الإدراج: الرقم، الرمز، العنوان، … بدل `serial+` / `secret+`.

## المرحلة D — تفعيل قوالب نقاط البيع
- إصلاح منطق «مسودة» الخاطئ لقوالب POS (`{qty} كرت {amount}`).
- إصلاح البذور: إعادة تفعيل القوالب المعيارية إن وُجدت متوقفة.
- مفتاح التفعيل يعمل.

## المرحلة E — إيقاف قوالب الرسائل الصادرة
- مفتاح لكل قالب صادر (نشط / متوقف) يُحفظ في `outbound_templates_disabled`.
- `OutboundTemplateGate` للتحقق قبل الإرسال (يُربط تدريجياً بمسارات الإرسال).
