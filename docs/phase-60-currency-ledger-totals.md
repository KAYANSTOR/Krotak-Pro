# المرحلة 60 — إجمالي الشريحة لكل عملة

**التاريخ:** 2026-10-02  
**الفرع:** `development/full-completion`  
**الأصل:** خارج نطاق المرحلة 59: «عملات غير YER».

## التنفيذ

- `sumLedgerSidesByCurrency` يجمع المدين والدائن لكل `currency_code` للحسابات المطابقة للشريحة.
- عضوية الشريحة تبقى من رصيد الريال اليمني المكتمل، حتى لا يختلف الفلتر عن القائمة.
- الحساب المدمج والحركة غير المكتملة خارج المجموع.
- بطاقات الشاشة تبقى بالريال اليمني، ويظهر سطر للعملات الأخرى إن وُجدت.
- الريال اليمني لا يُخلط مع عملة أخرى في نفس الرقم.

## خارج النطاق

- تبديل عملة عرض القائمة نفسها.
- تحقق جهاز حقيقي وأي عمل ترخيص.
