# المرحلة 55 — ترقيم صفحات الحسابات من SQL لكل الفلاتر

**التاريخ:** 2026-10-01
**الفرع:** `development/full-completion`
**الأصل:** بعد المرحلة 54 بقي فلتر «الكل» يحمّل عبر `search` ثم يُرتَّب في الذاكرة، والفلاتر الأخرى تُقطع عند 2000 صف.

## التنفيذ

- شاشة الحسابات تقرأ كل الفلاتر، بما فيها «الكل»، من `searchFilteredPage` بترتيب SQL نفسه.
- الصفحة 80 صفاً، والتمرير أو زر «عرض المزيد» يجلب الإزاحة التالية دون إعادة ترتيب الذاكرة.
- البحث عند الإرسال يستخدم نفس الاستعلام، فيبقى الترتيب والحد متسقين مع التصدير.
- اختبار الصفحة الثانية بعد ترتيب الرصيد تنازلياً.

## خارج النطاق

- عدّاد إجمالي منفصل عن الصفوف المحمّلة.
- تحقق جهاز حقيقي.
- أي عمل ترخيص.
