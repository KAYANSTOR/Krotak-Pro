# Phase 43-3 — العملاء والحسابات

**التاريخ:** 2026-09-21  
**الفرع:** `development/full-completion`  
**مرجع الخطة:** القسم 7 + المرحلة 3 من `krotak-pro-full-completion-plan.md`

## ما تم

- ملف العميل يعرض الاسم، الجوال الأساسي، المعرفات البديلة، الحالة، تاريخ الإنشاء، وعلاقة نقطة البيع إن وجدت.
- ملخص دفتر حقيقي: الرصيد، إجمالي الدين، الدفعات، المبيعات، السلف المفتوحة.
- قائمة العمليات تعرض النوع والمبلغ والبيان والحالة والمصدر/المرجع من الحركات المخزّنة.
- إضافة رصيد وخصم/تسوية عبر `CustomerBalanceService.credit` و`LocalSettlementService.settle` مع سبب إلزامي ومفتاح مرجع Idempotent وAudit القائم في الخدمات.
- حالة فارغة واضحة عند غياب الحركات.
- لا أرقام تجريبية.
- إصلاح تزامن: استعادة `AppContainerImpl` بعد أن أصبح الملف فارغاً وإبقاء تغليف `OutgoingDispatchQueue`.

## معيار القبول البرمجي
