# المرحلة 65 — تقدير إجماليات قائمة الحسابات بسعر العرض

**التاريخ:** 2026-10-03  
**الفرع:** `development/full-completion`  
**الأصل:** المرحلة 64 تحفظ سعر الصرف وتعرض التقدير داخل ملف العميل فقط.

## القرار

قائمة الحسابات تعرض تقديرًا للمدين والدائن عبر كل العملات الظاهرة في إجماليات الشريحة، بنفس أسعار العرض المحفوظة وبعملة القائمة المختارة.

التقدير لا يستبدل إجمالي العملة الأصلية ولا يعيد كتابة الحركات ولا ينشئ قيدًا. العملة بلا سعر تُستبعد وتُسمّى. إن لم توجد عملة أخرى ذات حركة مكتملة لا يُعرض سطر التقدير.

## خارج النطاق

- تثبيت السعر داخل الحركة أو إعادة تقييم الدفتر.
- سعر صرف تلقائي من شبكة، وعمل ترخيص، والتحقق على جهاز حقيقي.
