# المرحلة 61 — تبديل عملة عرض قائمة الحسابات

**التاريخ:** 2026-10-02  
**الفرع:** `development/full-completion`  
**الأصل:** خارج نطاق المرحلة 60: «تبديل عملة عرض القائمة نفسها».

## التنفيذ

- قائمة الحسابات تعرض رصيد العملة المختارة، لا الريال اليمني فقط.
- الترتيب حسب الرصيد والتصدير يستخدمان نفس عملة العرض.
- عضوية الشرائح (مدين/دائن/صفر) تبقى من رصيد الريال اليمني المكتمل حتى لا يتغيّر الفلتر مع تبديل العرض.
- بطاقات إجمالي المدين والدائن وورقة التوزيع تتبع عملة العرض ولا تخلط العملات.
- الريال اليمني يبقى الافتراضي، ويظهر مبدّل العملة فقط إذا وُجدت عملة أخرى في الشريحة.

## خارج النطاق

- تغيير عملة ملف العميل أو الدفتر نفسه — أُغلق في المرحلة 62 دون تحويل التاريخ.
- تحقق جهاز حقيقي وأي عمل ترخيص.
