# مرحلة 95 — اكتمال بيانات الأوراق التشغيلية

**التاريخ:** 2026-10-09  
**الأصل:** مرحلة 94 تعلّم اكتمال البيانات للشاشات المدفوعة، وتُبقي الأوراق والحوارات حتى خارج القياس.

## القرار

عند فتح ورقة تحمّل بيانات، تبدأ عينة `kind: sheet` بمعرّف ثابت. أول إطار يُعلَّم بعد الإطار التالي، واكتمال البيانات يُعلَّم بعد أول تحميل نجاحًا أو فشلًا:

- مخزون الكروت من لوحة التحكم.
- الكروت المباعة.
- البث بعد تحميل العملاء ونقاط البيع، وقبل معاينة النص.
- فئات الكروت بعد تحميل العمولات.

إعادة التحميل أو المعاينة لا تمسح العينة ولا تعيد ضبط الزمن. أوراق الإجراءات التي لا تحمّل قائمة، والحوارات، تبقى خارج القياس. القياس ما زال في الذاكرة وليس ميزانية ولا دليل جهاز.

## خارج النطاق

- لا ميزانية زمنية معتمدة.
- لا ادعاء تحسّن قبل/بعد.
- لا اكتمال بيانات لكل حوار أو ورقة إعدادات.
- لا اختبار جهاز حقيقي ولا Firebase Test Lab.
