# المرحلة 19 — ترقيم SQL وربط شاشة الحسابات باللقطة

**التاريخ:** 2026-09-25  
**الحالة:** منفّذة في الكود  
**الأساس:** المرحلة 18 وُثّقت كترقيم SQL، لكن العقد والشاشة كانا ما يزالان يقرآن كل الحسابات ثم `_rowFor`.

## النطاق

- `CustomerRepository.listAccountSnapshots` يقبل `limit` و`offset` بعد استبعاد `merged`.
- مسار البحث الفارغ يستخدم `LIMIT/OFFSET` على جدول `customers` في Drift.
- الأرصدة والهويات تُقرأ فقط لمعرّفات الصفحة الحالية.
- `CustomersScreen` يحمّل الصفحة الأولى من اللقطة ويطلب الصفحات التالية عند التمرير.
- InMemory والـ fakes تطابق العقد.

## خارج النطاق

- تشغيل بوابات الجهاز الحقيقية.
