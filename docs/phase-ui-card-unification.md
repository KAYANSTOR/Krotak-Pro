# توحيد بطاقات الواجهات المتبقية

**التاريخ:** 2026-09-18
**النطاق:** Presentation فقط.

## سياق المرحلة الرسمية

حسب [docs/progress.md](progress.md) المرحلة التالية الرسمية هي **Phase 12 (جهاز فقط)** وهي محظورة برمجيًا:
لا يُنفّذ برمجيًا ولا تُخترع نتائج جهاز.

لإكمالها يلزم:
1. تثبيت APK `1.0.11+11` على جهاز Android حقيقي.
2. تأكيد بصري (فاتح + داكن) للكروت والتقارير والعروض والبيع المباشر وفحص النظام.
3. تشغيل بوابات التحقق وتصدير حزمة الأدلة من شاشة تحقق الجهاز.
4. `readyForRelease` فقط بعد الحزمة المصدّرة من الجهاز.
