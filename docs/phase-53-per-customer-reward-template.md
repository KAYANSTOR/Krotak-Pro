# مرحلة 53 — قالب مكافأة مستقل لكل عميل داخل العرض

**التاريخ:** 2026-10-02  
**الأصل:** البند المؤجّل في المرحلة 52 («قالب مستقل لكل عميل داخل العرض نفسه»).

## القرار

قالب العرض يبقى افتراض كل عملائه. أي عميل يمكن أن يملك نص رسالة مكافأة خاصاً به داخل عرض واحد دون تغيير بقية العملاء أو العروض.

## التنفيذ

- الإعداد `promotion_reward_customer_sms_templates` خريطة JSON بمفتاح `معرّف العرض|معرّف العميل`.
- صرف المكافأة يقرأ قالب العميل أولاً، ثم قالب العرض، ثم القالب العام، ثم النص الافتراضي.
- مسح النص وحفظه يحذف التخصيص ويعيد العميل إلى قالب العرض.
- من قائمة العرض: «قالب لعميل» يبحث بالرقم أو الاسم ثم يحفظ لهذا العميل فقط.
- `{customer_name}` يُستبدل عند الإرسال مع متغيرات العرض والقيمة.

## خارج النطاق

- قالب عميل عام خارج عرض محدد. أُغلق في مرحلة 54.
- التحقق الميداني للرسالة على جهاز حقيقي يبقى عند المالك.
