# المرحلة 21 — ربط لوحة التحكم بعدّ COUNT والبث الحي

**التاريخ:** 2026-09-27  
**الأساس:** المرحلة 14 وُثّقت مكتملة بينما `DashboardScreen` ما زال يستدعي `listByStatus` لكل حالة انتباه.

## النطاق

- `_load` يعدّ الرسائل عبر `MessageRepository.countByStatus` بدل تحميل القوائم.
- بعد التحميل يُشترك في `watchCountByStatus` لحالات: مرفوضة · مستلمة · محلّلة · فاشلة.
- الشارة السفلية وعداد اللوحة يتحدّثان دون إعادة تحميل المخزون والمبيعات.
- الاشتراكات تُلغى في `dispose` وقبل إعادة الربط.

## خارج النطاق

- تحقق الجهاز الحقيقي.
- أسرار التوقيع.
