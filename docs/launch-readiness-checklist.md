# قائمة تحقق الإطلاق (جهاز + منطق)

## 1) استيراد الكروت
- [ ] رقم+رمز: دفعة صحيحة
- [ ] رقم فقط: دفعة صحيحة وSMS بلا سطر رمز
- [ ] تكرار رقم مرفوض

## 2) بث SMS
- [ ] معاينة مستلمين
- [ ] تأكيد «إرسال» إلزامي
- [ ] تقدّم ونتيجة نهائية
- [ ] لا تكرار لنفس المهمة

## 3) تكرار SMS / Idempotency
- [ ] نفس الرسالة مرتين → لا بيع مزدوج
- [ ] نفس external reference → رفض/تجاهل آمن

## 4) صلاحيات Android
- [ ] SMS
- [ ] جهات الاتصال (إن لزم)
- [ ] إشعارات المحافظ
- [ ] تجاهل تحسين البطارية

## 5) استرداد + Boot
- [ ] قطع أثناء SENDING ثم إعادة فتح → لا تكرار مالي
- [ ] إعادة تشغيل الهاتف → استئناف Worker

## 6) Fingerprint (تقني)
- [ ] عمود/مفتاح بصمة الرسالة مفعّل بعد codegen إن لزم

## 7) أدلة الجهاز
- [ ] تصدير حزمة الأدلة من شاشة التحقق
- [ ] `readyForRelease` فقط بعد الحزمة
