# مرحلة 68 — نافذة أوسع لطابور العميل عبر الفئات

**التاريخ:** 2026-10-04  
**الأصل:** مرحلة 67 تجمع كروت العميل عبر الفئات بحد 8 كروت ولمدة 24 ساعة، وتترك رفع الحد وتمديد المدة خارج النطاق.

## القرار

طابور العميل عبر الفئات يقبل حتى 32 كرتاً ويبقى صالحاً 7 أيام. إضافة كرت جديد تمدّد انتهاء الطابور إلى الموعد الأبعد. حجز الكرت في المخزون يستخدم المدة نفسها حتى لا يُحرَّر قبل انتهاء الطابور.

الطابور المشترك بلا عميل، وطابور الفئة، وطابور العميل داخل الفئة الواحدة يبقيان عند 8 كروت و24 ساعة. لا اختلاط بين هذه الطوابير.

لا قيد دفتر ولا بيع عند الحجز. خصم المخزون يبقى عند الصرف الفعلي فقط.

## خارج النطاق

- ضمان وصول الرسالة على جهاز حقيقي يبقى عند المالك وتقرير الناقل.
- لا إلغاء سقف الطابور بالكامل، حتى لا يتضخّم JSON الإعدادات.
- لا تمديد لطابور الفئة أو الطابور المشترك.
