# مرحلة 94 — اكتمال بيانات الشاشات التشغيلية المدفوعة

**التاريخ:** 2026-10-09  
**الأصل:** مرحلة 93 تعلّم اكتمال البيانات للتبويبات الرئيسية فقط، وتُبقي المسارات المدفوعة حتى أول إطار.

## القرار

بعد انتهاء أول تحميل — نجاحًا أو فشلًا — تُعلَّم العينة المفتوحة لنفس المعرّف الثابت:

- الرسائل المعلّقة والفاشلة والمرفوضة.
- ملف العميل.
- سجل العمليات.
- المحافظ ونقاط البيع.
- تقرير فترة المبيعات وتقرير نقاط البيع وكشف حساباتها.
- فحص النظام.

المعرّف يُمرَّر من `AppRoutes` ولا يُشتق من اسم الصنف. العلامة تُكتب مرة واحدة لكل فتح. إعادة التحميل لا تمسح العينة ولا تعيد ضبط الزمن. الإعدادات ومركز المساعدة والبيع المباشر تبقى حتى أول إطار لأنها ليست تحميل قائمة واحدًا. القياس ما زال في الذاكرة وليس ميزانية ولا دليل جهاز.

## خارج النطاق

- لا ميزانية زمنية معتمدة.
- لا ادعاء تحسّن قبل/بعد.
- لا اكتمال بيانات لكل ورقة أو حوار داخل الشاشة.
- لا اختبار جهاز حقيقي ولا Firebase Test Lab.
