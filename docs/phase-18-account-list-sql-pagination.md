# المرحلة 18 — ترقيم صفحات SQL لقائمة الحسابات

**التاريخ:** 2026-09-25  
**الحالة:** منفّذة في الكود  
**الأساس:** المرحلة 17 ربطت العقد ووثّقت الترقيم كمؤجّل، وشاشة الحسابات كانت ما تزال تبني الصفوف بـ `getBalance`/`listIdentifiers`.

## النطاق

- `CustomerRepository.listAccountSnapshots` يقبل `limit` و`offset` بعد استبعاد الحسابات المدمجة.
- Drift يقرأ الهويات والأرصدة للصفحة فقط، لا لكل العملاء.
- `CustomersScreen` يحمّل الصفحة الأولى من اللقطة ويطلب الصفحات التالية عند التمرير أو «تحميل المزيد».
- InMemory والـ fakes تطابق العقد حتى لا ينكسر التحليل.

## خارج النطاق

- دفع فلاتر الرصيد/غير المربوط إلى SQL.
- تشغيل بوابات الجهاز الحقيقية.
