# خطة تحديث الواجهات والهوية البصرية (UI / Theme Refresh)

> هذا المستند هو مرجع التتبع الرسمي لتحديث تصميم شاشات NET.
> **القاعدة الحاكمة:** لا تغيير في منطق الأعمال، ولا في الحسابات المالية، ولا في الربط
> مع البيانات. التغييرات محصورة في `lib/ui/**` + الخطوط + ملفات التوثيق.

## نطاق العمل الآمن (Out of Scope Guard)

لا يتم تعديل أي من:

- `lib/domain/**` (المنطق والأعمال والحسابات)
- `lib/data/**` (Drift / المستودعات)
- `lib/application/**` (Composition Root والمعالجات)
- `lib/platform/**` (الجسر الأصلي SMS/الإشعارات)

القراءة من نفس الخدمات تبقى كما هي؛ ما تغيّر هو طريقة العرض فقط.

## 1) أساس التصميم (مكتمل)

- **الخطوط:** Tajawal (6 أوزان) مُضمَّن في `assets/fonts` ومسجَّل في `pubspec.yaml`.
  سابقًا كان `fontFamily: 'Tajawal'` مطلوبًا في الثيم بينما الخط غير مُحمَّل إطلاقًا
  (لا قسم `fonts:` ولا `assets/`)، فكان التطبيق يرسم بالخط الاحتياطي. تم حذف
  الاعتماد غير المستخدم `google_fonts`.
- **رموز التصميم:** `lib/ui/theme/net_tokens.dart`
  - `NetSpacing` / `NetRadii` / `NetDurations` / `NetSizes`
  - `NetMotion` (يحترم خفض الحركة في النظام)
  - `NetElevation` (soft / raised / glow)
  - `NetTypography` (سلّم خطوط كامل بدل المقاسات العشوائية 11 / 11.5 / 13 …)
- **الثيم:** `lib/ui/theme/net_theme.dart` أصبح يعرّف Card / Dialog / BottomSheet /
  SnackBar / Chip / Buttons / Divider / Progress / ListTile، فأصبحت الشاشات ترث
  الأشكال والحدود بدل تكرارها.
- **الهوية اللونية:** تدرّج العلامة صار تعريفًا واحدًا
  (`KayanColors.brandGradientStart/End` + `NetSemanticColors`) بعد أن كان 3 نسخ مختلفة،
  وأُضيف `info` / `infoContainer` للاستخدام في بانرات المعلومات.
- `KayanPalette` أصبح يحمل `primary` ليُستخدم في الوضعين الفاتح والداكن.

## 5) لوحة التحكم (مكتمل)

- هيكل تحميل (Skeleton) بدل السبينر الكامل.
- بطاقة الرصيد: تدرّج العلامة الموحّد + هالة + عدّاد متحرك + شرائح بأيقونات.
- بطاقتا المؤشر: **منحنى اتجاه لآخر 7 أيام** (استعلام قراءة إضافي واحد فقط، لا يمسّ أي منطق).
- إجراءات سريعة: **شريط أفقي موحّد** بدل شبكة + FAB مزدوج (FAB أُزيل).
- تنبيهات قابلة للإخفاء ومرتّبة، وبانر للتحميل الجزئي بدل اختفاء اللوحة.
- «آخر العمليات» مجمّعة باليوم مع تسميات عربية للنوع والحالة والوقت النسبي.

## 3) توحيد الهيكل (مكتمل)

- `HomeShell` لم يعد يعرض `AppBar`؛ كل تبويب يعرض رأسه التصميمي وحده، فاختفت
  العناوين المكرّرة (شريط التطبيق + عنوان داخل الجسم).
- FAB المكرّر أُزيل، ووظائفه انتقلت إلى شريط الإجراءات + ورقة «المزيد».
- `refreshSignal` يخبر اللوحة بإعادة التحميل بعد أي عملية من شاشة أخرى.

## 13) التنظيف (مكتمل جزئيًا)

- إزالة تسريب أسماء enums الإنجليزية في `NetRecentTransactionCard`
  (`sale` / `completed` ← «صرف كرت» / «مكتملة»).
- المكوّنات الميتة المتبقية للإزالة في المرحلة 12:
  `widgets/dashboard/customer_balance_card.dart`،
  `widgets/dashboard/quick_actions_grid.dart`،
  `widgets/dashboard/sales_cards_row.dart`.

## التحقق (Verification)

بيئة التنفيذ الحالية **لا تحتوي Flutter/Dart SDK**، لذلك لم يُشغَّل `flutter analyze`
ولا `flutter test` هنا. يجب تشغيلهما محليًا بعد السحب:

```bash
flutter pub get
flutter analyze --no-fatal-infos
flutter test
```

الاختبارات التي تم تحديث توقّعاتها لتطابق الواجهة الجديدة:

- `test/widget/net_components_test.dart` → تسميات عربية + انتظار انتهاء عدّاد المبالغ.

> ملاحظة: `flutter pub get` سيُزيل `google_fonts` من `pubspec.lock` لأن الاعتماد حُذف
> من `pubspec.yaml` (كان غير مستخدم في أي ملف).
