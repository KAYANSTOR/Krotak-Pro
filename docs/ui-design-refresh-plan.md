الربط مع البيانات. لم يُعدَّل أي ملف من `lib/domain/**` أو `lib/data/**` أو `lib/application/**`
أو `lib/platform/**`.

```
git diff --stat 3ca5ebe..HEAD -- lib/domain lib/data lib/application lib/platform
→ (فارغ: لا تغييرات في طبقات المنطق والبيانات)
```

## 2) الأساس (المرحلة 1)

- **الخط:** Tajawal (6 أوزان) مُضمَّن في `assets/fonts` ومسجَّل في `pubspec.yaml`.
  قبل ذلك كان الثيم يطلب `fontFamily: 'Tajawal'` بلا أي ملف خط ولا `assets/`، فكان كل النص
  العربي يُرسم بالخط الاحتياطي. حُذف الاعتماد غير المستخدم `google_fonts`.
- **رموز التصميم** (`lib/ui/theme/net_tokens.dart`): `NetSpacing`, `NetRadii`, `NetDurations`,
  `NetSizes`, `NetMotion` (يحترم `disableAnimations`), `NetElevation` (soft/raised/glow),
  `NetTypography` (سلّم خطوط بدل المقاسات العشوائية).
- **الثيم** (`net_theme.dart`): Card / Dialog / BottomSheet / SnackBar / Chip / Buttons /
  Divider / Progress / ListTile — فلن تحتاج الشاشات لتعريف الأشكال يدويًا.
- **الهوية اللونية:** تدرّج العلامة تعريف واحد (`KayanColors.brandGradient*`)، وأُضيف
  `info` / `infoContainer`، وأصبح `KayanPalette.primary` متاحًا للوضعين.

## 4) ما نُفِّذ شاشة بشاشة

- **لوحة التحكم:** هيكل تحميل، بطاقة رصيد بتدرّج العلامة + عدّاد متحرك، مؤشرات مع **منحنى
  اتجاه آخر 7 أيام** (استعلام قراءة إضافي واحد)، شريط إجراءات أفقي (وأُزيل FAB المكرر)،
  تنبيهات قابلة للإخفاء وبانر للحالة الجزئية، وآخر العمليات مجمّعة باليوم مع تسميات عربية
  وأوقات نسبية.
- **التقارير:** 3 بطاقات KPI (مرفوضة/قيد المعالجة/فاشلة) من `OpsReportService`، بطاقة ملخص
  مبيعات، وصفوف مجمّعة بلون دلالي لكل قسم.
- **العروض:** تبويبات بعدّادات، بطاقة لكل عرض (عتبة/مكافأة/حالة)، أوراق موحّدة `NetSheet`،
  وحذف اللون البنفسجي الخارج عن الهوية (استُبدل بلون العلامة).
- **الحسابات:** شريط ملخص (إجمالي المدين/الدائن محسوبًا من الصفوف المحمّلة)، أفاتار حرف أول
  ثابت اللون، **تصحيح دلالي**: المديونية كانت تُعرض دائمًا بلون أخضر، الآن شارة رصيد دلالية
  (`NetBalancePill`)، فلاتر بعدّادات.
- **الكروت:** مقياس مخزون مقسّم (متاح/محجوز/مباع)، شرائح فئات بعدد المتاح، إخفاء/إظهار
  الرموز مع زر نسخ، وأوراق بثيم النظام.
- **سجل العمليات:** ملخص ثابت أعلى القائمة، فلتران (نوع/تاريخ) كشرائح، تجميع باليوم مع رؤوس
  أيام عربية، شريحة حالة لكل عملية، حالات تحميل هيكلية وحالة فارغة بزر «مسح الفلاتر».
- **الإعدادات:** بحث (نطاق الأقسام) + **بطاقة جاهزية التشغيل** (المعالجة التلقائية، تنبيه
  التدخل، سلفني، المظهر) مع رابط مباشر لفحص النظام + رأس بوصف.
- **معالج الصلاحيات:** شاشة واحدة بمؤشر تقدّم (1/N)، حالة تحقق حيّة لكل خطوة
  (تم التحقق / غير مفعّل / اختياري / جارٍ الفحص)، أزرار: التنفيذ، فتح الإعدادات، إعادة
  الفحص، والتالي — بدل سبعة حوارات مانعة متتالية.

## 6) المتبقي والمؤجَّل (بأسباب)

1. **تدرّجات الحالة الفاتحة الثابتة** في بعض شاشات الرسائل والقوالب:
   `pending_messages_screen.dart`, `rejected_messages_screen.dart`, `failed_messages_screen.dart`,
   `settings/templates_screen.dart`, `wallets_pos_screen.dart`.
   السبب: هذه الألوان الفاتحة مُقترنة بنصوص داكنة، وهي **مقروءة في الوضعين**؛ تحويلها إلى
   ألوان داكنة دون تحويل النص المقترن بها في نفس الكتلة كان سيُنتج نصًا غير مقروء.
   تُركت كعنصر تلميع نهائي مُوثَّق بدل تنفيذها بشكل ناقص.
2. **إجراءات السحب (Swipe) في الحسابات** (اتصال/SMS): تتطلب إضافة حزمة صلاحيات جديدة
   (`url_launcher`/`flutter_phone_direct_caller`) — لم تُضف أي تبعية جديدة بدون موافقة.
   البديل الحالي: البطاقة كلها قابلة للضغط وتفتح التفاصيل.
3. **شريط تقدّم لكل عرض ترويجي في شاشة العروض**: لا تتوفر بيانات تقدّم في تلك الشاشة
   (كتالوج العروض فقط)، ورفضت توليد أرقام وهمية.
4. **انتقال Hero** بين بطاقة الرصيد وسجل العمليات: لا توجد واجهة مقابل في الشاشة الهدف.
5. **بحث الإعدادات** يعمل على نطاق الأقسام (كلمات مفتاحية لكل قسم) وليس على صف واحد بعينه،
   لأن بناء الصفوف يدويًا داخل أقسام ثابتة.
6. **إجراءات الحساب الفردي:** لا حذف/أرشفة من الشاشة (تغيير منطقي، خارج النطاق).

## 7) التحقق

بيئة التنفيذ الحالية **لا تحتوي Flutter/Dart SDK** (تحقّق: `which flutter dart` → غير موجود)،
والمساحة الحرة على القرص غير كافية لتثبيت SDK، لذلك **لم يُشغَّل** أي من الأمرين التاليين هنا:

```bash
flutter pub get
flutter analyze --no-fatal-infos
flutter test
```

> `flutter pub get` سيُزيل `google_fonts` من `pubspec.lock` (حُذف من `pubspec.yaml` لأنه غير
> مستخدم في أي ملف).

بديل التحقق الذي نُفِّذ في هذه البيئة (فحوصات ثابتة على الشجرة):

```bash
# لا ملف يستخدم KayanColors بدون استيراده
# لا ملف يستخدم NetSpacing/NetRadii/NetTypography خارج net_tokens أو ملفات part
# لا مراجع متبقية للمكوّنات المحذوفة
# لا بناء KayanPalette خارج ملفه
```
