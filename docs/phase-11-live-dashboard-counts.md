# المرحلة 11 — مزامنة فورية لأعداد رسائل اللوحة

**التاريخ:** 2026-09-22  
**المصدر:** تدقيق 21 أيلول §4 بند 6 — «مزامنة فورية للوحات عند وصول رسالة جديدة (Stream من Drift)»

## المشكلة
لوحة التحكم كانت تعيد تحميل قوائم `listByStatus` كاملة لحساب الشارة، ولا تتحدث إلا بسحب/إشارة خارجية.

## الحل
1. `MessageRepository.watchCountByStatus` — بث COUNT من Drift.
2. `_load` يستخدم `countByStatus` لا القوائم.
3. بعد أول تحميل ناجح تُشترك اللوحة في البث وتحدّث الشارة دون إعادة بناء كل اللوحة.

## معيار القبول
- وصول/تغيير حالة رسالة يحدّث عدّاد المعلّقة/المرفوضة والشارة السفلية دون انتظار دورة خلفية.
- لا تحميل صفوف كاملة لمجرد العدّ.
