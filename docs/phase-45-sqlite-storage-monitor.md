# المرحلة 45 — مراقبة حجم SQLite وسياسة الاحتفاظ

**التاريخ:** 2026-10-01  
**الفرع المستهدف:** `development/full-completion`  
**الأصل:** البند 16 من المتبقي في `docs/phase-26-audiences-branding-pos-validation.md`

## الهدف

إظهار حجم قاعدة Drift/SQLite الحقيقي للمشغّل، وربط ذلك بسياسة الاحتفاظ اليدوية القائمة، دون جدولة خلفية تلقائية ودون المساس بالقيود المحاسبية أو المخزون.

## التنفيذ

- `LocalMaintenanceService.measureStorage()` يقرأ `PRAGMA page_count` و`page_size` و`freelist_count`.
- عتبة تحذير ثابتة: 80 ميبيبايت.
- شاشة «تنظيف السجلات» تعرض الحجم الحي والمساحة القابلة للاسترداد بعد VACUUM.
- `formatStorageBytes` دالة نقية للعرض العربي.
- الاختبارات لا تفتح قاعدة إنتاج.
