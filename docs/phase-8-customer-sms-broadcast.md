# Phase 8 — Customer SMS Broadcast (Complete)

**تاريخ:** 2026-09-17  
**الحالة:** مكتملة برمجيًا — قياس المعدل على جهاز حقيقي

## التدفق

```text
نص الرسالة → معاينة المستلمين → تأكيد بكلمة «إرسال»
  → إنشاء BroadcastJob + fingerprint
  → إرسال عبر MessageSender مع تقدّم
  → نتيجة لكل مستلم (sent / failed)
```

## قواعد

- مستلم مؤهل: عميل `active` + هاتف قابل للتطبيع.
- يُستبعد: محظور / مدمج / مؤرشف / بلا رقم.
- تأكيد صريح: كتابة كلمة **إرسال**.
- منع تكرار نفس النص + نفس مجموعة المستلمين (fingerprint).
- لا يستهلك رصيد ترخيص الكروت.
- إيقاف / إلغاء مدعومان من الخدمة.
