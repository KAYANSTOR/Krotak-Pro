# قواعد العمل المعتمدة مؤقتًا

## البيع / التسوية / التحويل / التدقيق / الاستعادة

- البيع ذري من رصيد نشط مع FIFO وحجز.
- التسوية تخصم رصيدًا مكتملًا مع idempotency بالمرجع.
- SMS: حفظ ثم تحليل ثم معالجة؛ الاستعادة تعيد `received`/`parsed` فقط.
- Audit على العمليات الحرجة.
