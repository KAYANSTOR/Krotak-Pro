# Phase 7 — Bulk Card Import Performance

**تاريخ:** 2026-09-13

## الهدف

تسريع استيراد دفعات الكروت دون تغيير قواعد المخزون: منع تكرار الرقم التسلسلي والرمز السري قبل الاعتماد، والتحقق من الملف أولاً، ثم الإدخال على دفعات مع تقدم حقيقي.

## ما تم تنفيذه

- تحقق مسبق من الصفوف الفارغة والتكرار داخل الملف.
- بحث مجمع عن الأرقام والرموز الموجودة (`existingSerialsAmong` / `existingSecretsAmong`) بدل استعلام لكل صف.
- إدخال عبر `saveAll` على دفعات حجمها 200 داخل وحدة العمل الحالية.
- تقرير `CardImportReport`: عدد المستورد، المتجاوز، وأخطاء كل صف.
- واجهة الاستيراد تعرض شريط تقدم أثناء الدفعات.
- الصفوف الصالحة تُعتمد حتى مع وجود صفوف مرفوضة؛ إذا رُفضت الدفعة بالكامل تُرجع `card_import_rejected`.
