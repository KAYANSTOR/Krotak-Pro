# Phase 7 — Bulk Card Import (Complete)

**تاريخ:** 2026-09-17  
**الحالة:** مكتملة في المستودع

## أنواع الكروت عند الاستيراد

| الوضع | المعنى | الصق / ملف |
|--------|--------|------------|
| **رقم + رمز** (`serialAndPin`) | رقم الكرت + PIN/سر | `serial,secret` أو `;` أو tab |
| **رقم فقط** (`serialOnly`) | رقم الكرت بلا PIN | سطر = رقم واحد |

- الاختيار من واجهة الاستيراد (مفرد / مجموعة).
- `CardImportParser.parse(raw, format: …)`.
- `importCards` يقبل سرًا فارغًا فقط في `serialOnly`.
- رسالة التسليم: `cardDeliverySmsBody` — بلا سطر «الرمز» إن كان السر فارغًا.

## مسار الاستيراد

1. اختيار الفئة.
2. اختيار نوع الكرت (رقم+رمز / رقم فقط).
3. مفرد أو دفعة (لصق/ملف).
4. تحقق تكرار داخل الملف + تكرار في المخزون.
5. حفظ داخل UnitOfWork + Audit `cards_imported`.
