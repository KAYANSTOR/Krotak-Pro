# Phase 18 — أدلة قياس الجهاز (استيراد وبث)

**تاريخ:** 2026-09-16  
**الحالة:** منفذة في المستودع / بانتظار تشغيل جهاز حقيقي  
**الأساس:** المتبقي بعد Phase 17: بوابات Phase 12 + قياس الاستيراد والبث.

## النطاق

- توسيع حمولة `device_verification_gates` لتشمل الحالة + ملاحظة المشغّل + مقاييس رقمية + وقت التسجيل.
- التوافق الخلفي مع الصيغة القديمة `{ "gateId": "passed" }`.
- منع تأكيد `passed` لبوابتي `bulk_import` و`broadcast_rate` دون ملاحظة قياس.
- واجهات مساعدة: `recordImportMeasurement` و`recordBroadcastMeasurement`.
- شاشة تحقق الجهاز تطلب ملاحظة عند تأكيد بوابات القياس وتعرض الدليل المحفوظ.

## خارج النطاق

- اختراع نتائج `passed` من بيئة التطوير أو CI.
- تشغيل فعلي على جهاز Android أو قياس Google Play.
