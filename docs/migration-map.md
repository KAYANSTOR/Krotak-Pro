# خريطة النقل من Kotlin إلى Flutter

## مرجع الواجهات

المستودع المرجعي هو:

https://github.com/KAYANSTOR/kayan-android-kotlan

## أولويات الشاشات

### P0 — التشغيل الأساسي

- التفعيل والترخيص.
- لوحة التحكم.
- العملاء والحسابات.
- المحافظ ونقاط البيع.
- الكروت.
- فئات الكروت.
- البيع المباشر والمخزون.
- الإعدادات الأساسية.
- سجل العمليات.

### P1 — التشغيل التجاري

- التقارير.
- تقرير المبيعات.
- تقرير نقاط البيع.
- الرسائل المرفوضة والمعلقة.
- قوالب العملاء.
- محاكاة القوالب.
- قوالب التحويل ومعالجتها.
- التجديد.
- إعدادات SIM والبطارية.

### P2 — الصيانة والتوسع

- تصدير السجل.
- تنظيف السجلات.
- التنظيف العميق.
- النسخ الاحتياطي المشفر والاستعادة.
- مركز المساعدة.
- العروض والمكافآت وسلفني.

## قاعدة النقل

يُنقل الشكل والتدفق المرئي، ويُعاد بناء الحالة والمنطق والبيانات باستخدام Domain وRepositories وUse Cases. لا يُنسخ `MainActivity` أو `remember mutableStateOf` إلى Flutter كمصدر حقيقة.
