# مرحلة 93 — اكتمال بيانات التبويبات الرئيسية

**التاريخ:** 2026-10-09  
**الأصل:** مرحلة 92 تقيس أول إطار لكل التبويبات والمسارات المدفوعة، وتعلّم اكتمال البيانات للوحة الرئيسية فقط.

## القرار

بعد انتهاء تحميل التبويب — نجاحًا أو فشلًا — تُعلَّم العينة المفتوحة لنفس المعرّف:

- `reports` بعد لقطة التقارير.
- `offers` بعد قائمة العروض أو خطأ القائمة.
- `accounts` بعد صفوف الحسابات أو خطأ البحث.
- `cards` بعد الفئات والكروت أو خطأ التحميل، وقبل مزامنة تنبيه المخزون على الجهاز.

العلامة تُكتب مرة واحدة لكل فتح. إعادة التحميل لا تمسح العينة ولا تعيد ضبط الزمن. المسارات المدفوعة تبقى حتى أول إطار فقط. القياس ما زال في الذاكرة وليس ميزانية ولا دليل جهاز.

## خارج النطاق

- لا ميزانية زمنية معتمدة.
- لا ادعاء تحسّن قبل/بعد.
- لا اكتمال بيانات لكل شاشة مدفوعة.
- لا اختبار جهاز حقيقي ولا Firebase Test Lab.
