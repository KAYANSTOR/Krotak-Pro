# مرحلة 45 — مراقبة حجم SQLite وسياسة الاحتفاظ

**التاريخ:** 2026-10-01  
**الأصل:** البند 16 من المتبقي في `phase-26` بعد إغلاق تصدير التدقيق (مرحلة 44).

## الهدف

إظهار حجم قاعدة البيانات الحقيقي وسياسة الاحتفاظ للمشغّل، دون أرقام ثابتة ودون حذف الدفتر المالي.

## التنفيذ

- `RetentionPolicy`: معالجة 3 أيام، مرفوض/مستنفد 30 يوماً، ونص عربي ثابت بأن الدفتر والكروت والعملاء وسجل التدقيق لا تُحذف تلقائياً.
- `LocalMaintenanceService.inspectDatabase`: `page_count * page_size` و`freelist_count` وعدد الرسائل.
- شاشة تنظيف السجلات تعرض الحجم والمساحة القابلة للاسترجاع وعدد الرسائل مع نص السياسة.
- اختبار تنسيق الحجم وقراءة pragma على قاعدة ذاكرة.
