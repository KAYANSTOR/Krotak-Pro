# NET Domain Model — الإصدار الأول

هذه الوثيقة تصف العقود الأولية فقط. لا تمثل قاعدة بيانات ولا Backend ولا تدّعي اكتمال القواعد التجارية.

## كيانات الدومين

الكيانات الأولية هي العميل ومعرفاته، المحفظة، نقطة البيع، فئة الكروت، الكرت وحجزه، الحركة، البيع، الرسالة الواردة، قالب التحويل، الترخيص، وقيمة مالية صحيحة بوحدات صغرى.

## قرارات تقنية مثبتة

- المبالغ لا تستخدم `double`؛ تمثل كـ integer minor units مع رمز عملة.
- حالة الكرت منفصلة عن حجزه، حتى يمكن تمثيل عملية الحجز المؤقت بوضوح.
- الرسالة الواردة تحفظ بهوية مستقلة وحالة معالجة مستقلة.
- العقود الحالية Repository interfaces فقط، ولا يوجد تنفيذ تخزين أو API.
- العقود تعيد `Result<T>` بدل رمي أخطاء غير موحدة.

## قواعد لم تُحسم بعد

لا يزال مطلوبًا اعتماد العملة، سياسة التقريب، ترتيب اختيار الكرت، مدة الحجز، تعريف العميل المكرر، قواعد دمج الحسابات، قواعد التسوية والعكس، حدود سلفني، شروط العروض والمكافآت، وشكل مفاتيح الترخيص.

لن تُكتب هذه القواعد في الكود قبل اعتماد أمثلة نجاح وفشل لكل قاعدة.

## ما لم يُنفذ عمدًا

لم تُضف قاعدة بيانات، أو Drift/SQLite، أو API، أو State Management، أو SMS Receiver، أو UI إنتاجي. هذه الطبقة تمثل نقطة فصل آمنة بين المواصفات والتنفيذ اللاحق.
