# المرحلة 59 — إجمالي الشريحة لا الدفتر كاملاً

**التاريخ:** 2026-10-02  
**الفرع:** `development/full-completion`  
**الأصل:** خارج نطاق المرحلة 58: «إجمالي نقدي لكل شريحة فلتر على حدة».

## التنفيذ

- `sumLedgerSides` يقبل `AccountSqlFilter` ويطبّق نفس شرط شريحة الحسابات قبل الجمع.
- بطاقات المدين والدائن في شاشة الحسابات تُحدَّث مع الشريحة والبحث، لا من الصفحة المحمّلة.
- شريحة «رصيد صفر» تعيد صفرًا للطرفين. المؤقت وبلا رقم يجمعان أرصدة الحسابات المطابقة فقط.
- الحساب المدمج والحركة غير المكتملة يبقيان خارج المجموع.

## خارج النطاق

- عملات غير `YER`.
- تحقق جهاز حقيقي وأي عمل ترخيص.
