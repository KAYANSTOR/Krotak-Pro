## الاسم الرسمي

الاسم الرسمي والوحيد للمنتج:

**Krotak Pro — كروتك برو**

ويستخدم هذا الاسم في:
- اسم التطبيق الظاهر للمستخدم.
- الوثائق والخطط الجديدة.
- الهوية التجارية.
- وصف المنتج.
- لوحة الإدارة.
- الإشعارات.
- المواد الموجهة للمستخدم.

## اسم المستودع المستهدف

اسم مستودع تطبيق Android المستهدف بعد إعادة التسمية:

**KAYANSTOR/Krotak-Pro**

الاسم الحالي للمستودع هو **KAYANSTOR/net-flutter**، ويجب اعتباره اسمًا تقنيًا قديمًا إلى حين تنفيذ إعادة التسمية الرسمية في GitHub.

## لوحة الإدارة

المشروع الإداري المستقل:

**KAYANSTOR/Krotic-Admin-App**

وهو مشروع لوحة التحكم المركزية لـ Krotak Pro.

## قاعدة تسمية إلزامية للخطط والوكلاء

- لا تستخدم NET أو NET Flutter أو net-flutter كاسم المنتج.
- استخدم Krotak Pro كاسم المنتج.
- لا تنشئ أي مستند خطة جديد باسم NET أو net-flutter.
- عند الإشارة إلى مستودع التطبيق الحالي قبل إعادة تسمية GitHub، اكتب: **المستودع الحالي (سيعاد تسميته إلى KAYANSTOR/Krotak-Pro)**.
- أي معرّفات برمجية داخلية قديمة مثل net_app أو com.kayan.net_app لا تُغيَّر تلقائيًا إلا ضمن مهمة Migration مستقلة ومتكاملة، لأن تغييرها يتطلب تحديث جميع الاستيرادات والمسارات والـ Android package declarations معًا.
- الاسم الظاهر للمستخدم يجب أن يكون Krotak Pro / كروتك برو حتى لو بقيت بعض المعرّفات الداخلية المؤقتة.

## بوابة عدم الكسر

إعادة التسمية التجارية لا تعني إعادة هندسة النظام.

أي Migration للمُعرّفات الداخلية أو package namespace يجب أن يتم في مرحلة منفصلة، مع تحديث شامل للمراجع وعدم ترك imports أو Android components مكسورة.
