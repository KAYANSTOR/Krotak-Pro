# المرحلة 64 — سعر صرف للعرض دون تحويل التاريخ

**التاريخ:** 2026-10-03  
**الفرع:** `development/full-completion`  
**الأصل:** خارج نطاق المرحلة 63: «تحويل الأرصدة التاريخية أو سعر صرف».

## القرار

المشغّل يحفظ سعرًا اختياريًا: كم ريالًا يمنيًا يساوي وحدة كبرى واحدة من عملة أجنبية. ملف العميل يعرض تقديرًا محوّلًا لمجموع الحركات المكتملة إلى عملة الحساب، عبر الريال.

السعر لا يُعاد كتابته داخل الحركات، ولا يغيّر الرصيد الأصلي، ولا يُنشئ قيدًا. العملة بلا سعر تُستبعد من التقدير وتُسمّى، ولا تُحسب صفرًا. مسح السعر يحذف التخصيص. الريال اليمني بلا سعر لأنه المرجع.

## خارج النطاق

- تثبيت سعر الصرف داخل حركة تاريخية أو إعادة تقييم الدفتر.
- سعر صرف تلقائي من شبكة، وعمل ترخيص، والتحقق على جهاز حقيقي.
