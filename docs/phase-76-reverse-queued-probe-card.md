# مرحلة 76 — عكس ترتيب طابور المعاينة

**التاريخ:** 2026-10-05  
**الأصل:** مراحل 72–75 تحرّك الكرت الظاهر إلى الرأس أو الذيل أو بمقدار موضع واحد. لا يوجد عكس لترتيب الطابور كله دفعة واحدة.

## القرار

المشرف يستطيع عكس ترتيب الطابور الذي يحمل الكرت الظاهر. الحجوزات تبقى مربوطة بكل كرت، وموعد انتهاء الطابور لا يتغير. إذا كان الطابور كرتاً واحداً أو ترتيبه لا يتغير بالعكس، لا يُكتب شيء جديد.

العكس لا يمس طابور عميل آخر، ولا طابور الفئة داخل العميل، ولا الطابور المشترك بلا عميل. لا قيد دفتر ولا بيع. خصم المخزون يبقى عند الصرف الفعلي فقط. أزرار الخطوة والرأس والذيل تبقى للتحريك الموضعي.

## خارج النطاق

- ضمان وصول الرسالة على جهاز حقيقي يبقى عند المالك وتقرير الناقل.
- لا إلغاء سقف الطابور بالكامل، حتى لا يتضخّم JSON الإعدادات.
- لا دمج الطوابير في طابور واحد.
- لا سحب حر إلى موضع رقمي يختاره المشغّل؛ العكس يقلب الترتيب الحالي فقط.
