# المرحلة 54 — ترتيب الرصيد داخل SQL

**التاريخ:** 2026-10-01
**الفرع:** `development/full-completion`
**الأصل:** خارج نطاق المرحلة 53: ترتيب الرصيد كان بعد قراءة الصفحة، فيقتصر حد 2000 والتصدير على ترتيب الاسم.

## التنفيذ

- `AccountSqlSort` يفرض الترتيب داخل استعلام الفلتر: الأعلى رصيداً، الأقل رصيداً، الاسم، الأحدث إنشاءً.
- الرصيد الموقّع من الحركات المكتملة فقط، ثم الاسم والمعرّف لكسر التعادل.
- شاشة الحسابات تعيد التحميل عند تغيير الترتيب وتمرّر نفس الترتيب للتصدير.
- صفحة `limit/offset` تُقطع بعد الترتيب، لا قبله.
- ترتيب القيمة المطلقة أُلغي لأنه كان يخالف تسمية «الأعلى/الأقل رصيداً».
