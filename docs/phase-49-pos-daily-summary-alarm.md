# المرحلة 49 — منبّه منتصف الليل لملخص نقاط البيع

**التاريخ:** 2026-10-01  
**الفرع:** `development/full-completion`  
**الأصل:** البند 13 في `docs/phase-26-audiences-branding-pos-validation.md`، بعد اكتمال المرحلة 48.

## المشكلة

ملخص نقاط البيع اليومي كان يُرسل فقط عندما تعمل دورة الاسترداد والتطبيق حي. الإعداد يعد المشغّل بالإرسال عند منتصف الليل، دون منبّه نظام.

## التنفيذ

- `nextDailySummaryFire` يثبت موعد 00:05 بالتوقيت المحلي.
- `DailySummaryAlarm` يجدول `AlarmManager` (دقيق إن سُمح، وإلا غير دقيق) ويعيد الجدولة بعد كل إطلاق وبعد الإقلاع.
- المستقبل يعلّم الاسترداد ويحاول فتح `MainActivity` حتى يستدعي المسار الحالي `sendDue`.
- مفتاح الإعداد يعيد جدولة المنبّه أو يلغيه، ويُزامَن عند إقلاع التطبيق.
- القفل اليومي داخل `LocalPosDailySummaryService` يبقى مصدر منع التكرار.

## خارج النطاق

- ضمان الإيقاظ بعد Force-stop أو قيود OEM. الدورة الحالية تبقى الاحتياط.
- نسخ Google Drive.
- أي عمل ترخيص.
