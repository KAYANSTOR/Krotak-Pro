# دفعة 22 — فتح ملف العميل من البيع المباشر + تصدير كشف الحساب

**التاريخ:** 2026-09-19
**النطاق:** واجهات فقط. لم يُعدّل أي منطق أعمال أو قاعدة بيانات أو خدمة أو مستودع أو استعلام بيع.

## لماذا هذه الدفعة؟

وثيقة مطابقة الفيديو ودفعة 21 سجّلتا فرقَين عرضيّين متبقيين قابلين للتنفيذ برمجيًا:

1. زر فتح ملف العميل من داخل ورقة البيع المباشر عندما يُكشف عميل موجود.
2. تصدير كشف الحساب (نسخ / حفظ ملف نصي) من شاشة تفاصيل العميل.

تحقق الجهاز الحقيقي ما زال محظورًا ولا يُنفَّذ من بيئة البناء.

## ما تم

### 1. ورقة البيع المباشر
- حفظ `customer.id` مع الاسم عند نجاح `findByIdentifier` (قراءة فقط كما كان).
- شارة «عميل موجود» أصبحت قابلة للضغط وتُظهر أيقونة فتح.
- الضغط يغلق الورقة ثم يفتح `CustomerDetailScreen` بالمعرّف نفسه عبر المسار القائم.

### 2. شاشة تفاصيل العميل
- زر مشاركة ينسخ كشف حساب نصي (الاسم، الجوال، الرصيد، آخر العمليات الظاهرة).
- زر حفظ يكتب الملف في مستندات التطبيق بنفس أسلوب حفظ إيصال الحركة (بدون حزمة PDF جديدة).

## خارج النطاق
- لا PDF ثنائي أصلي (لا اعتماد جديد في pubspec).
- لا نتائج جهاز حقيقي ولا لقطات مخترعة.
