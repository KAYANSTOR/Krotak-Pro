# مرحلة 28 — طلبات رصيد نقاط البيع

**التاريخ:** 2026-09-20  
**الأصل:** البند 1 من المتبقي في [phase-26-audiences-branding-pos-validation.md](phase-26-audiences-branding-pos-validation.md)

## الهدف

تفعيل القالب الخامس المزروع لكل نقطة بيع («قالب طلب رصيد نقطة البيع»، العينة `111`) كمسار مستقل عن التحويل:

1. مطابقة رمز الطلب على جسم الرسالة (وليس كمبلغ بيع).
2. استخراج هوية نقطة البيع من رقم المُرسل.
3. فرض حد يومي لكل نقطة بيع.
4. الرد بقالب `pos_balance_response_template` برصيد الدفتر والدين.
