# المرحلة 63 — عملة أساسية دائمة للحساب

**التاريخ:** 2026-10-03  
**الفرع:** `development/full-completion`  
**الأصل:** خارج نطاق المرحلة 62: «عملة أساسية دائمة للحساب تُحوّل كل الحركات التاريخية».

## القرار

كل حساب يحفظ عملة عرض دائمة. فتح ملف العميل يعود إليها، وتعديل الرصيد والتصدير يستخدمانها. اختيار الريال اليمني يمسح التخصيص.

لا تُعاد كتابة الحركات التاريخية ولا يُحوَّل مبلغ من عملة إلى أخرى. الحركة الجديدة تُسجَّل بعملة الحساب الحالية فقط.

## التنفيذ

- المفتاح `customer_account_currency` خريطة معرف العميل إلى رمز ISO من ثلاثة أحرف.
- الرمز غير المعروف يُرفض. العملة المخزّنة تبقى ظاهرة حتى قبل أول حركة بها.
- النسخ الاحتياطي يضم المفتاح مع بقية الإعدادات.

## خارج النطاق

- تحويل الأرصدة التاريخية أو سعر صرف.
- عمل ترخيص أو تحقق جهاز حقيقي.
