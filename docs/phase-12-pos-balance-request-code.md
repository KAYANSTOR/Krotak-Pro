# المرحلة 12 — رمز طلب رصيد مستقل لكل نقطة بيع

**التاريخ:** 2026-09-22  
**المصدر:** تدقيق 21 أيلول §4 بند 7 — «وضع طلب رصيد مخصّص لكل نقطة بيع بدل الرمز الموحّد»

## المشكلة
رمز الاستعلام الافتراضي `111` كان موحّداً لكل نقاط البيع. عند وجود أكثر من نقطة أو رغبة المشغّل في رمز مختلف، لا يمكن تخصيص الرمز من شاشة النقطة وربطه بقالب الاستعلام.

## الحل
1. الحقل موجود في `PosAccount.balanceRequestCode` (الافتراضي `111`).
2. `LocalPosProfileService.create/update` يحفظ الرمز مع ملف النقطة.
3. `DefaultPosTemplatesSeeder` يزرع/يحدّث قالب `balance-request` بنص الرمز الخاص بالنقطة فقط، دون overwrite لبقية القوالب المخصّصة.
4. شاشة نقاط البيع: حقل «رمز طلب الرصيد» عند الإنشاء والتعديل، وعرض الرمز على بطاقة النقطة.
5. المحلّل يبقى على مطابقة `pattern == body` بعد التطبيع؛ الهوية تبقى من رقم المرسل.

## معيار القبول
- إنشاء نقطة برمز `222` يجعل رسالة `222` من رقم النقطة طلب رصيد.
- تعديل الرمز إلى `333` يحدّث قالب الاستعلام لهذه النقطة فقط.
- الرمز الفارغ يعود إلى `111`.
- اختبار: `create and update persist a custom per-POS balance request code`.
