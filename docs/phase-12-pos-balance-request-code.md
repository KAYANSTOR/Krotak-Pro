# المرحلة 12 — رمز طلب رصيد مخصص لكل نقطة بيع

**التاريخ:** 2026-09-22  
**المصدر:** تدقيق 21 أيلول §4 بند 7 — «وضع طلب رصيد مخصّص لكل نقطة بيع بدل الرمز الموحّد»

## المشكلة
قالب استعلام الرصيد كان يُزرع دائماً بالنص `111` لكل نقاط البيع. المشغّل الذي يريد رمزاً مختلفاً لنقطة معيّنة كان يضطر لتعديل القالب يدوياً، والرمز لم يكن جزءاً من ملف نقطة البيع.

## الحل
1. حقل `PosAccount.balanceRequestCode` (الافتراضي `111`) يُحفظ مع حساب نقطة البيع.
2. شاشة نقاط البيع تعرض حقل «رمز طلب الرصيد».
3. `DefaultPosTemplatesSeeder` يزرع/يحدّث قالب `balance-request` بنص الرمز المخزّن دون إعادة تفعيل قالب أوقفه المشغّل.
4. الهوية تبقى من رقم المرسل؛ الرمز يطابق جسم الرسالة فقط.

## معيار القبول
- إنشاء نقطة بيع برمز `222` يزرع قالباً نمطه `222`.
- تعديل الرمز يحدّث نمط القالب المزروع.
- السجلات القديمة بلا حقل تُقرأ كـ `111`.
