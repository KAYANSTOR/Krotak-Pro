# دفعة 25 — تصدير كشف الحساب نصًا وصورة

**التاريخ:** 2026-09-19
**النطاق:** واجهات فقط. لم يُغيَّر عقد الخدمات ولا مخطط قاعدة البيانات ولا pubspec.

## لماذا هذه الدفعة؟

تقرير مطابقة الفيديو سجّل «تصدير كشف / مشاركة كصورة» كعنصر عرض مفقود.
دفعة 22 وثّقت النسخ والحفظ النصي، لكن شاشة تفاصيل العميل في المستودع لم تكن تملك أزرار التصدير بعد.

تحقق الجهاز الحقيقي ما زال خارج النطاق (مرحلة 12).

## ما تم

- دالة `buildCustomerStatementText` تجمع الاسم والجوال والرصيد وآخر العمليات الظاهرة فقط.
- زر مشاركة في شريط تفاصيل العميل يفتح ورقة تصدير.
- نسخ إلى الحافظة، حفظ `.txt`، وحفظ `.png` عبر `RepaintBoundary` بدون حزمة PDF أو مشاركة خارجية جديدة.
- اختبار وحدة لنص الكشف.

## خارج النطاق

- لا اعتماد `pdf` أو `share_plus`.
- لا نتائج جهاز حقيقي ولا لقطات مخترعة.
