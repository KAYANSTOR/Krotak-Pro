1. تعبئة GitHub Secrets الأربعة ثم `workflow_dispatch` لإثبات بناء موقّع.
2. تنفيذ `docs/phase-8-device-verification-checklist.md` على جهاز Android حقيقي (صلاحيات، SMS وارد/صادر، إعادة تشغيل، استيراد، نسخ/استعادة).
3. إثبات تقرير تسليم الناقل على جهاز (المرحلة 10).
4. فرع `licensing` يبقى خارج هذه الخطة.
